# Auditoría de UI - antislop-ui

**Fecha:** 2026-10-01
**Objetivo:** `src/app/screens/dashboard.html`, `src/app/layout/shell.html`

## Hallazgos (Findings)

1. **[FIXED - C-3 / R-20] Default Dashboard Shell:** El layout del dashboard actual (4 tarjetas arriba, tabla abajo, panel lateral derecho) es el template genérico de administración por defecto. La sección "Estado de unidades" está ahí solo porque "un dashboard debe tener paneles", pero muestra "Próximamente". Si no cumple una función real ahora, debe eliminarse para no quitar foco a los datos reales (Gastos y Reservas).
2. **[FIXED - C-2 / R-26] Controles no funcionales en Shell:** El buscador (`<input placeholder="Buscar...">` en `shell.html`) no estaba conectado a ninguna lógica (no tiene `ngModel` ni manejador de eventos). Es un input falso ("mockup"). Fue retirado del código hasta que su backend exista.
3. **[FIXED - R-05] Copy-Paste Feature Cards:** Las 4 tarjetas KPI usaban idéntica jerarquía visual. Las de métricas futuras ("Próximamente") ahora tienen un tratamiento visual distinto (fondo gris, borde punteado, opacidad) para no competir con los datos reales, manteniendo la grilla de 4.
4. **[FIXED - R-31] Decoración innecesaria en Scrollbar:** Se eliminaron las reglas globales de CSS `::-webkit-scrollbar` que imponían un scroll "diseñado". Ahora el navegador delega esta responsabilidad a la UI nativa del sistema operativo, respetando configuraciones de accesibilidad y modos de auto-ocultamiento (como en macOS o móviles).
5. **[FIXED - R-04] Iconos Lucide genéricos:** Se oficializó el uso de `lucide-angular` en el `DESIGN.md`. Ahora es una decisión consciente y documentada: la estética de trazo fino (stroke 1.75) se usa intencionalmente para reforzar la identidad corporativa y profesional del sistema, dejando de ser simplemente "los iconos que vienen por defecto".
